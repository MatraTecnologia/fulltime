# Fundação — Plataforma Full Time (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a fundação do monorepo Full Time — Turborepo com `apps/web` (Next.js) e `apps/api` (Fastify), design system com a paleta da marca, e autenticação ponta a ponta (better-auth) com área logada protegida.

**Architecture:** Monorepo pnpm + Turborepo. `apps/api` (Fastify 5, ESM, `@fastify/autoload`) segue as convenções do `spotdrive-back`, expõe better-auth em `/auth` e usa Prisma 7 (`@prisma/adapter-pg`). `apps/web` (Next.js 16, App Router) consome o `packages/ui` (tokens Tailwind v4 + primitivos) e fala com a API via cliente better-auth + fetch. Roles globais `admin|instrutor|profissional`.

**Tech Stack:** pnpm 11, Turborepo 2.10, Next.js 16, React 19, Tailwind v4, Fastify 5.8, better-auth 1.6, Prisma 7.8 + @prisma/adapter-pg, PostgreSQL, TypeScript 5.9, tsx.

## Global Constraints

- **Package manager:** pnpm 11.9 (workspaces). Nunca `npm`/`yarn` nos apps.
- **API:** ESM puro (`"type":"module"`), imports relativos com extensão `.js`, dev via `tsx watch src/server.ts`, build via `tsc`. Roteamento exclusivamente por `@fastify/autoload` (1 subpasta de `src/routes/` = 1 plugin; nome da pasta = prefixo da rota; `index.ts` exporta `default async function(app: FastifyInstance)`).
- **Toda rota Fastify** inclui `schema: { tags: [...], summary: '...' }` (Swagger/Scalar).
- **Banco:** PostgreSQL + Prisma 7 com `@prisma/adapter-pg`. Client Prisma só existe em `apps/api`; o `web` nunca importa Prisma.
- **Roles:** `admin`, `instrutor`, `profissional`. Default no signup = `profissional`.
- **Código:** `const` arrow functions (não `function` declarations) no código de aplicação — exceto o `export default async function(app)` exigido pelo padrão autoload da API. Sem comentários supérfluos, sem `console.log` em código entregue.
- **Paleta da marca (hex exatos):** navy `#003060`, amber `#F5B500`, green `#6CB23A`, blue `#119BD8`, purple `#834BA8`, surface `#F7F9FB`.
- **Acessibilidade:** contraste mínimo AA, foco visível, `prefers-reduced-motion` respeitado, alvos de toque ≥44px.
- **Commits:** frequentes, um por task concluída.

```ts
import 'dotenv/config'
import Fastify from 'fastify'
import fastifyCors from '@fastify/cors'
import fastifyStatic from '@fastify/static'
import fastifySwagger from '@fastify/swagger'
import ScalarApiReference from '@scalar/fastify-api-reference'
import autoload from '@fastify/autoload'
import { fileURLToPath } from 'url'
import { join, dirname } from 'path'

const __dirname = dirname(fileURLToPath(import.meta.url))

const app = Fastify({ logger: true, trustProxy: true })

await app.register(fastifyCors, {
  origin: [process.env.FRONTEND_URL ?? 'http://localhost:3000'],
  methods: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE', 'OPTIONS'],
  credentials: true,
  allowedHeaders: ['Content-Type', 'Authorization'],
})

await app.register(fastifyStatic, {
  root: join(__dirname, '..', 'public'),
  prefix: '/static/',
  decorateReply: false,
})

await app.register(fastifySwagger, {
  openapi: { info: { title: 'Full Time API', version: '1.0.0' } },
})

await app.register(ScalarApiReference, { routePrefix: '/docs' })

await app.register(autoload, { dir: join(__dirname, 'routes') })

const port = Number(process.env.PORT) || 3333
await app.listen({ port, host: '0.0.0.0' })
```

```ts
import type { FastifyRequest, FastifyReply } from 'fastify'
import { fromNodeHeaders } from 'better-auth/node'
import { auth } from './auth.js'

export type Session = NonNullable<Awaited<ReturnType<typeof auth.api.getSession>>>
export type Role = 'admin' | 'instrutor' | 'profissional'

declare module 'fastify' {
  interface FastifyRequest {
    session: Session
  }
}

export const requireAuth = async (request: FastifyRequest, reply: FastifyReply) => {
  const session = await auth.api.getSession({ headers: fromNodeHeaders(request.headers) })
  if (!session) return reply.status(401).send({ error: 'Não autorizado.' })
  request.session = session
}

export const requireRole = (...roles: Role[]) => {
  return async (request: FastifyRequest, reply: FastifyReply) => {
    if (!request.session) return reply.status(401).send({ error: 'Não autorizado.' })
    const role = request.session.user.role as Role
    if (!roles.includes(role)) {
      return reply.status(403).send({ error: `Permissão insuficiente. Requer: ${roles.join(', ')}` })
    }
  }
}
```

```ts
import type { FastifyInstance } from 'fastify'
import { auth } from '../../lib/auth.js'

export default async function authRoutes(app: FastifyInstance) {
  app.route({
    method: ['GET', 'POST'],
    url: '/auth/*',
    schema: { tags: ['auth'], hide: true },
    async handler(request, reply) {
      const url = new URL(request.url, `http://${request.headers.host}`)
      const headers = new Headers()
      for (const [key, value] of Object.entries(request.headers)) {
        if (value) headers.append(key, Array.isArray(value) ? value.join(',') : value)
      }
      const req = new Request(url, {
        method: request.method,
        headers,
        body: ['GET', 'HEAD'].includes(request.method) ? undefined : JSON.stringify(request.body),
      })
      const res = await auth.handler(req)
      reply.status(res.status)
      res.headers.forEach((value, key) => reply.header(key, value))
      reply.send(res.body ? await res.text() : null)
    },
  })
}
```

- **Integração Fastify ↔ better-auth** (Task 6, Step 4): o bridge manual `Request`→`auth.handler` é o ponto mais frágil (serialização de body, content-length). **Antes de implementar, conferir via Context7 a doc atual do better-auth 1.6 para Fastify/Node** — pode haver helper oficial (`toNodeHandler`/`toFastify`) mais robusto que o bridge manual. Validar com o teste de sign-up do Step 6.
- **Nome do cookie de sessão** (Task 8, Step 6): better-auth usa `better-auth.session_token` por padrão. Se a verificação mostrar redirect indevido, conferir o nome real do cookie no DevTools e ajustar o `matcher`/nome.
- **CORS + cookies cross-origin:** em dev, API (`:3333`) e web (`:3000`) são origens distintas; `credentials: true` no CORS (Task 4) + `baseURL` no `authClient` (Task 8) já cobrem isso. Em produção, usar `COOKIE_DOMAIN` compartilhado.
